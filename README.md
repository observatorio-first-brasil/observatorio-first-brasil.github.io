# Observatório FIRST Brasil

Painel público de desenvolvimento de equipes brasileiras de FTC e FRC, de 2023 a 2026.

Site estático: publique esta pasta na raiz do repositório e configure GitHub Pages para a branch main, pasta / (root). A página inicial separa os ambientes FTC e FRC.

Fontes: FTCScout, Statbotics e The Blue Alliance. A metodologia e a cobertura estão descritas no próprio painel.
